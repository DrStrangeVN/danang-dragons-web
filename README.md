# Danang Dragons — Fan Site 🐉

Website fan-made (tiếng Việt) về đội bóng rổ **Danang Dragons** (VBA) — "Rồng sông Hàn".

- Thiết kế: nền đen + cam đặc trưng, font Be Vietnam Pro (Google Fonts, đầy đủ dấu tiếng Việt)
- Nội dung: tổng quan, lịch sử & thành tích các mùa, đội hình, cầu thủ nổi bật, vé & sân nhà (Nhà thi đấu Quân khu 5), nhà tài trợ, cộng đồng
- Static site — deploy trực tiếp lên Vercel, không cần build step

## Deploy

Dự án là static HTML/CSS/JS. Trên Vercel: import repo này, không cần cấu hình build.
